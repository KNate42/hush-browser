# Hush

Браузер для Windows на основе Firefox ESR. Сайт не узнает, что вы переключились на другую вкладку, ушли из окна или вставили текст из буфера. А вкладки, которыми вы не пользуетесь, выгружаются из памяти.

Автор: [KNate42](https://github.com/KNate42)

## Что умеет

Режим защиты выбирается для каждого сайта отдельно: выключен, обычный или строгий.

Вкладка выгружается через 5 минут без использования. Исключения: активные и закреплённые вкладки, вкладки со звуком, с камерой, микрофоном или показом экрана и те, где вы ввели текст.

Строгая защита от отслеживания и uBlock Origin уже встроены, телеметрия выключена.

На 20 вкладках Hush занял 820 МиБ с выгрузкой и 3841 МиБ без неё. Как это мерили, написано в [docs/design.md](docs/design.md).

Анонимным Hush вас не сделает: сайт по-прежнему видит ваш IP-адрес, а если вы вошли, то и аккаунт.

## Установка

Нужны Windows и Python 3.

```
py scripts/setup.py
```

Скрипт скачает Firefox ESR и uBlock Origin с серверов Mozilla, проверит контрольную сумму Firefox и соберёт браузер в папке `app/`.

## Запуск

Откройте `Hush.cmd`. Профиль создастся в папке `profile/`, а установленный у вас Firefox останется нетронутым.

Поменяли что-то в `extension/` или `config/`? Пересоберите браузер:

```
py scripts/build.py
```

## Проверка

Тестам нужны пакеты `selenium` и `psutil` и `geckodriver.exe` в папке `.cache/gd/`.

```
py tests/test_signals.py
```
