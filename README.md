# Hush

Браузер для Windows на основе Firefox ESR. Скрывает от сайтов ваши действия: переключение вкладок, потерю фокуса, вставку текста. Вкладки, которыми вы не пользуетесь, выгружаются из памяти.

Автор: [KNate42](https://github.com/KNate42)

## Что делает

- Сайт не узнаёт, что вы ушли на другую вкладку или вставили текст из буфера.
- Для каждого сайта можно выбрать режим: выключен, обычный или строгий.
- Вкладка выгружается через 5 минут без использования. Не выгружаются активные и закреплённые вкладки, вкладки со звуком, с камерой, микрофоном или показом экрана и вкладки с введённым текстом.
- Встроены строгая защита от отслеживания и uBlock Origin. Телеметрия выключена.

Замер на 20 вкладках: 820 МиБ с выгрузкой и 3841 МиБ без неё. Методика и подробности описаны в [docs/design.md](docs/design.md).

Hush не делает вас анонимным: сайт по-прежнему видит ваш IP-адрес и ваш аккаунт, если вы вошли.

## Установка

Нужны Windows и Python 3.

```
py scripts/setup.py
```

Скрипт скачает Firefox ESR и uBlock Origin с серверов Mozilla, проверит контрольную сумму Firefox и соберёт браузер в папке `app/`.

## Запуск

Запустите `Hush.cmd`. Профиль создастся в папке `profile/`, установленный Firefox останется нетронутым.

После правок в `extension/` или `config/` пересоберите браузер:

```
py scripts/build.py
```

## Проверка

Тестам нужны пакеты `selenium` и `psutil`, а также `geckodriver.exe` в папке `.cache/gd/`.

```
py tests/test_signals.py
```
